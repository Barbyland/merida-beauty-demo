Conectar Google Calendar
  1. Con Barby Digital, abrí Google Apps Script y creá un proyecto llamado MERIDA · Prueba de reservas.
  2. Copiá el código de conexión completo en Código.gs y guardalo.
  3. Elegí la función prepararPrueba y ejecutala. Google solicitará autorización para los calendarios y para enviar los avisos por correo. La función verifica las dos agendas de ensayo.
  4. En el registro de ejecución aparece una clave de conexión. Copiala en el campo inferior. No la publiques ni la envíes por chat.
  5. Elegí Implementar → Nueva implementación → Aplicación web, ejecutar como vos (Barby Digital). El acceso del endpoint debe permitir solicitudes sin iniciar sesión (Cualquier usuario); el código exige la clave para cada operación y solo permite las dos agendas PRUEBA. Copiá su URL terminada en /exec.

La clave se guarda únicamente en esta computadora y no se incorpora a la web pública. Esta conexión es para el ensayo local.
